# Fuentes de las imágenes sociales (`/og/...`)

Las imágenes que se generan para compartir cada artículo usan las mismas fuentes que la web, en WOFF porque el motor de `next/og` no lee WOFF2. Solo el subconjunto latino (incluye tildes, ñ y «»).

- `space-grotesk-latin-400-normal.woff`, `space-grotesk-latin-600-normal.woff`: Space Grotesk, de @fontsource/space-grotesk 5.3.0. Licencia SIL Open Font License 1.1.
- `jetbrains-mono-latin-400-normal.woff`: JetBrains Mono, de @fontsource/jetbrains-mono 5.3.0. Licencia SIL Open Font License 1.1.
